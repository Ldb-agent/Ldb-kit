Ldb-kit 사이트 설명 및 사용법

배경 및 개요

Ldb-kit 사이트는 AI Workspace Platform의 키트 소개 지도다. 설치 패키지가 아니라, Cursor/Claude에서 쓰는 명령·스킬·에이전트·훅이 어떻게 이어지는지를 한 화면 플로우 맵으로 보여 준다.1

공개 URL: https://ldb-agent.github.io/Ldb-kit/ · 소스: 저장소 docs-site/ · main 푸시 시 catalog 변경이 있으면 Pages에 반영된다.

한 줄 부제: 문서 목록이 아니라, 분기와 연결을 탐색하는 인터랙티브 맵.

맵으로 보는 기본 사용 흐름

flowchart LR
  open[사이트 열기] --> find[입구·스킬 찾기]
  find --> click[노드 클릭]
  click --> panel[사이드 패널 확인]
  panel --> cursor[Cursor 또는 Claude에서 /명령 실행]

본선 핵심 경로:

flowchart LR

  ideaNo[아이디어 없음] --> ideation --> brainstorm
  brainstorm --> plan --> policy --> devrule
  devrule --> verify --> commit

Cursor·Claude에서의 대응 사용법

사이트는 무엇을 부를지를 보여 주고, 실제 실행은 IDE에서 한다.

상황 사이트에서 볼 노드 IDE에서 할 일
아이디어 정제 brainstorm /brainstorm
태스크 분해 plan /plan
정책·약관 policy Discord /policy · /terms 또는 OS Policy
코드 구현 devrule /devrule
콘텐츠 ybagent (EXTRA) /ybagent
회의 문서 makerdocu (EXTRA) /makerdocu → 로컬 python -m makerdocu generate
목록 확인 help /help
Ldb-kit Pages는 보고서 HTML 미리보기 서버가 아니다. MakerDocu 편집·인쇄·PDF는 로컬 makerdocu/ 엔진으로 한다.

Claude Code 플러그인 설치 (동료)

설치 절차는 아래만 따르면 된다.

  1. LDB가 GitHub 공유 계정을 전달한다: dreamerly.app@gmail.com
  2. 초대 메일을 수락한다.
  3. Claude Code에서 순서대로 입력한다.
/plugin marketplace add Kkumteul-app/ai-workspace-platform

입력 이후:

/plugin install ldb-kit@ldb-kit
  1. 설치가 끝나면 /help, /brainstorm 등으로 바로 사용한다.
로컬 경로·모노레포 sync·Discord 설정은 기본 설치에 필요 없다. MakerDocu·YBagent 엔진이 안 되면 그때 node "$CLAUDE_PLUGIN_ROOT/scripts/setup-engines.mjs" 한 번만 실행한다.

핵심 시사점

사이트의 역할은 온보딩 지도다. “무슨 스킬이 있고 어디에 붙는지”를 먼저 보고, 실행은 Cursor/Claude/Discord로 이어가면 된다.

Skill과 Agent 색을 나눈 이유는 맵에서 워크플로 단계와 전문 차출을 한눈에 구분하기 위함이다.

EXTRA(ybagent·venture·makerdocu·db)는 코어 키트와 섞지 않고 따로 두어, woojoo 호환 본선을 유지한다.

결론 및 제언

  1. 신규 기여자는 GitHub 초대(dreamerly.app@gmail.com) 수락 후 Claude Code에서 marketplace add → install만 한다.
  2. 사이트 https://ldb-agent.github.io/Ldb-kit/ 에서 입구·본선·EXTRA를 클릭해 본다.
  3. 작업 시 사이드 패널의 트리거·산출물 경로를 기준으로 /명령을 고른다.
  4. 키트에 노드를 추가하면 docs-site/src/data와 catalog를 함께 갱신한 뒤 main에 푸시한다.
  5. 회의·보고 문서는 사이트 EXTRA의 makerdocu를 확인한 뒤 /makerdocu + 로컬 generate로 산출한다.
